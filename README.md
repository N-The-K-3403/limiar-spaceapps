# web/ - public site (Vercel)

English only. Spec: `FEATURES.md`. React + Vite, built from scratch in this folder.

## Run locally
```
npm --prefix web install
npm --prefix web run dev        # dev server
npm --prefix web run build      # production build into web/dist
node web/scripts/check_model.mjs  # checks the browser scorer reproduces 12/17, 9/12, 5/6 and 34/38
python src/sync_web_data.py     # refresh web/public data from the project CSVs and results/
```

## Deploy (Vercel)
1. Add New Project -> import the repo.
2. Root Directory = `web`; Framework Preset = Vite (build `npm run build`, output `dist`).
3. Add `GEMINI_API_KEY` as a Vercel environment variable. The `api/chat` and `api/parse` serverless functions read it on the server; never expose it in client code or prefix it with `VITE_`.
4. To inspect full prompts and Gemini responses in Vercel Function Logs, temporarily set `GEMINI_DEBUG=true` and redeploy. Turn it off after debugging; logs include user prompts and context, but never the API key.

## What exists (build 1)
- Tabs: Estimator, Evidence, Models, Sources (working); Canvas, Investigations, Graph (placeholders).
- Estimator: Takahashi spread/extinct model, weights read from `public/models/takahashi_live_model.json`; domain check per input, nearest real cases, held-out counts computed from the JSON.
- Evidence: 39 SoFIE-GEL points (5 verified, 34 estimated) with provenance markers, no-data bands, CSV export.
- Not yet: MARGIN-Limit weights export, fitted curve on the evidence chart, graph.json, Gemini assistant, Canvas, Investigations ranking, landing page.

## Data in `public/` (never edited by hand; generated by `src/sync_web_data.py`)

- `data/sofie_points.json`, `data/takahashi_cases.json`, `data/manifest.json` - each row has `provenance` and `source`.

## Publishing rules
- Do not republish paper figures (T'ien 2025 is CC BY-NC-ND); show figure-derived values as estimated numbers with the source.
- No NASA logo, no images of people or minors, no unverified third-party data (`data/FIRE-X-main/`).
- Cite sources and licenses on the page (Takahashi 2026 CC BY; T'ien 2025 CC BY-NC-ND; NASA PSI).
